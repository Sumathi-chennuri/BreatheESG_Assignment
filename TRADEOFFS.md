# Tradeoffs

## Database

SQLite was selected instead of PostgreSQL.

Reason:

- Faster setup
- Lightweight
- Good for assignment scope

Limitation:

- Not ideal for large production systems.

---

## CSV Upload

Simple CSV upload implementation used.

Reason:

- Easy implementation
- Fast data ingestion

Limitation:

- No validation for incorrect file format.

---

## UI Design

Simple dashboard UI used.

Reason:

- Focus on functionality.

Limitation:

- No charts or analytics visualizations.

---

## Authentication

Admin authentication only used.

Reason:

- Reduced complexity.

Limitation:

- No custom user login system.
