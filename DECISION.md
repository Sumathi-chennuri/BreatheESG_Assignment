# Design Decisions

## Backend Choice

Django was selected because it provides:

- Fast API development
- Built-in Admin Panel
- ORM support
- Easy database integration

---

## Frontend Choice

React was selected because:

- Component-based architecture
- Easy API integration
- Fast UI development
- Dynamic rendering support

---

## Database Choice

SQLite was used because:

- Simple setup
- No separate installation needed
- Suitable for assignment projects

---

## API Design

Django REST Framework was used to create:

- GET API for records
- POST API for CSV upload

---

## CSV Processing

Pandas library was used to:

- Read CSV files
- Parse rows
- Insert records into database
